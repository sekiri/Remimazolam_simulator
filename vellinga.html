患者情報 Vellinga 2025

remifentanil の PK は Eleveld 2017 の3コンパートメント allometric 式（補遺 D790 の固定値）。remimazolam / 代謝物 CNS7054 は補遺 D790 の refit 固定値（70kg基準）。

0 = 負荷なし（TCIのみ）

TCI 方式：投与速度 = ターゲット × CL（remifentanil の個人CL）。試験と同様にターゲット血中濃度を指定。

モデル出典 参考文献

remimazolam PK: Vellinga et al., Anesthesiology 2025 補遺 D790 の refit 固定値（70kg基準 3コンパートメント, V1=5.31 / V2=12.81 / V3=40.04 L, CL=1.15, Q2=0.91, Q3=0.29 L/min, 代謝分率 FM=0.80）。

代謝物 CNS7054: 見かけの CL=0.05 L/min, V5≈7.8 L, ktr≈0.30。

レミフェンタニル PK: Eleveld et al., Anesthesiology 2017 の3コンパートメント allometric モデル（補遺 D790 の固定 THETA）。

相互作用: remifentanil が代謝物の分解を競合的に抑制（IC50=8.0 ng/mL, Hill=0.6）→ 代謝物蓄積（急性耐性）。

PD: MOAA/S と BIS を補遺 D791 の refit 値で予測（remimazolam + 代謝物 + remifentanil の相加）。旧 dose-finding 論文の EC50B=35.79 / EC50M=43.03 は参考のみ（本モデルは 3期間横断 refit 値 EC50B≈180 / EC50M≈5.3 を採用）。
